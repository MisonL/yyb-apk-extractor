单文件 CLI 程序（index.js），以 shebang `#!/usr/bin/env node` 作为入口并通过 package.json 的 `bin` 字段暴露全局命令 `yyb-apk-extractor`。整体按职责划分为若干内聚函数块：参数解析（parseArgs/parseTimeoutMs/parseDownloader/parseConnections）、输入校验与安全（normalizeUrl/getPkgName/safeTencentUrl/validateProxy/validateDownloadDir）、网络请求（基于 Node 内置 http/https 模块请求应用宝移动端 simple.jsp 及 sj.qq.com 搜索页）、下载器调度（selectDownloader 在 curl/aria2c/wget 之间选择，通过 spawnSync 调用外部二进制）、临时配置写入（writeTempConfigFile 生成带权限控制的 aria2c/curl 配置文件并在进程退出时清理）、交互模式（readline 驱动 search/select/download/get/proxy/timeout/doctor/help/exit 子命令）以及 doctor 环境检查。依赖方向单向：CLI 入口 → 解析/校验 → 网络层 → 下载器 → 输出；不引入任何第三方 npm 依赖，全部能力由 Node 标准库 + 可选系统命令实现。安全边界集中在 safeTencentUrl 白名单域名、sanitizeTerminalOutput 过滤 ANSI/控制字符、maskProxySecrets 脱敏凭据、spawnSync 数组参数避免 shell 注入。
