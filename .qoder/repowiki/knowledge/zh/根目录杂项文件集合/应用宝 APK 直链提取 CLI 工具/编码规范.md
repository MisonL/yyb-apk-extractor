- 所有用户输入（包名、URL、代理、下载目录、关键词等）在进入业务逻辑前均经过显式校验函数处理，失败时抛出带中文提示的 Error。
- 对外部命令统一通过 spawnSync 以参数数组形式调用，并使用 buildCommandInvocation 对 Windows .cmd/.bat 脚本做引号转义与 ComSpec 包装，禁止 shell 拼接。
- 代理凭据通过 splitProxyAuth 剥离后仅在必要处重建 URL，子进程环境变量与日志输出统一经 maskProxySecrets/maskUrl 脱敏后再回显。
- 网络目标域名通过 safeTencentUrl 与 ALLOWED_SEARCH_HOSTNAMES 白名单限制为 *.qq.com / *.myapp.com / *.qpic.cn / *.qlogo.cn，防止 SSRF。
- 终端彩色输出通过 shouldUseColor + createColors 工厂按需启用，受 NO_COLOR 环境变量与 --no-color 选项控制，非 TTY 管道场景自动禁用颜色。
- 临时配置文件使用 writeTempConfigFile 写入 os.tmpdir 下 mkdtemp 目录，设置 0o700/0o600 私有权限，并通过 installTempCleanupHandlers 在 SIGHUP/SIGINT/SIGTERM/SIGBREAK 等信号中统一清理。
